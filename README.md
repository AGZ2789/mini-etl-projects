# Mini ETL Projects

A collection of tiny beginner-friendly ETL projects in Python using pandas.  
Each folder contains a self-contained script and instructions.

## Projects

- **etl-pass-fail**  
  Creates a dataset of scores, adds `Passed` and `Failed` columns, and saves results to CSV.

- **simple-etl**  
  Cleans a small dataset, drops missing values, and saves cleaned results to CSV.

## How to Run
Clone the repo, install pandas, and run any script:

```bash
pip install pandas
python etl-pass-fail/etl-pass-fail.py
